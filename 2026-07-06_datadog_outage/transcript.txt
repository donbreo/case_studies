doesn't stop at one table. It can contain many at once, which raises the question: if there is more
than one , who decides which table a particular package will use? So Linux responds to this with a
separate list, which is a list of rules. You see this by running the IP rule. So, each rule checks
one property of the package and points it to the table. One rule says that if a packet comes from
this source address , table five is used. Another rule says that if it has this particular mark,
table seven is used. Another rule says that if the packet came through this network interface, use
table 12. So the kernel reads the list from top to bottom, stops at the first rule that matches, and
that is the table that the packet uses. And all of this is just policy-based routing, and typically
you route a packet to its destination. This allows you to route it by its origin, label, or the
interface it arrived on. And this is the mechanism behind most serious Linux networking, such as

these two facts together. Cilium only works as long as its policies remain loaded in the kernel, and
